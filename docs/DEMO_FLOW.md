# Munmai Demo Flow

Flow for portfolio walkthroughs, recruiter demos, or interview screenshares.

## 1. Login

- Open `https://munmai.com`.
- Log in with a demo account.
- Mention JWT auth and protected user-owned data.

## 2. Dashboard

- Show all-time personal balance, income, expenses, shared money, Monthly Control, and Debt Reality preview.
- Explain that Dashboard is an overview, not an operational dumping ground.

## 3. Add Income or Expense

- Go to Transactions.
- Open the add transaction modal.
- Add an income or expense.
- Show how transactions feed Dashboard, Monthly Summary, Receipts, Tax Pack, and Monthly Control.

## 4. Import CSV

- Go to Import CSV.
- Upload a CSV file.
- Show how rows enter a review queue first.
- Classify rows as income, expense, debt payment, transfer, or ignore.
- Skip a row to show safe exclusion.
- Commit reviewed rows and show the import summary.

## 5. Debt Reality

- Open Debt Reality.
- Show total debt, monthly debt pressure, due soon count, and active debts.
- Record a payment and explain how it reduces the liability balance over time.

## 6. Monthly Summary

- Open Monthly Summary.
- Change month/year.
- Show income vs expenses, net flow, category breakdown, recent transactions, budget status, and debt pressure.

## 7. Groups and Shared Expenses

- Open Groups.
- Show a group summary.
- Add a shared expense.
- Show balances and settlements.
- Show invite/member management and join-code flow if relevant.

## 8. Opening Balance and Settings

- Open Opening Balance.
- Explain that it is a starting money position, not monthly income.
- Open Settings.
- Show account details, app context, and data links.

## Closing Talking Point

Munmai is designed around financial clarity: manual entry when needed, review-first imports, explicit debt pressure, and group balances that can be settled over time.
