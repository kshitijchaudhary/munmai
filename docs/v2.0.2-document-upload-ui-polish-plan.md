# Munmai v2.0.2 — Document Upload UI Polish Plan

## Goal

Improve the visual trust, clarity, and usability of Munmai document upload areas without changing backend behavior.

This release focuses on upload UI polish only.

---

## Why This Release Exists

Munmai now supports receipt uploads and CSV/PDF statement imports. The workflows work, but the upload UI still feels basic.

v2.0.2 should make upload areas feel more trustworthy and product-ready.

---

## Target Areas

- Receipt Inbox upload card
- Import Statements upload card

---

## Recommended Scope

- [ ] Replace plain file input presentation with a larger upload-zone style card
- [ ] Show accepted file types clearly
- [ ] Show file size guidance where available
- [ ] Show selected file name more clearly
- [ ] Improve spacing and visual hierarchy
- [ ] Keep current upload behavior
- [ ] Preserve dark/light mode
- [ ] Avoid backend changes

---

## Candidate UI Direction

Use the generated LinkedIn mockup as visual inspiration only.

Practical UI elements:

- document/upload icon
- clear heading
- helper text
- accepted file types
- selected file state
- existing choose file behavior
- clean action button

---

## Out of Scope

- OCR
- AI receipt parsing
- receipt-to-expense linking
- bank sync
- new upload APIs
- real drag-and-drop requirement
- file compression
- JPG-to-PDF conversion
- subscription billing
- full redesign
